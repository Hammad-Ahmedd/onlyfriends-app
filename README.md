# OnlyFriends

**Find people nearby, privately.**

OnlyFriends is an Android app that shows people around you who chose to be visible, with privacy modes, a live map, follow, private chat, crowd detection and blocking.

Built by Hammad Ahmed as a Design and Analysis of Algorithms (DAA) course project, using spatial hashing, a KD-tree and a Top-K max-heap for fast nearby search.
